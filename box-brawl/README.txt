BOX BRAWL - Build & Shoot Arena (1v1.LOL x Fortnite style)

HOW TO RUN
  Unzip, then open index.html in Chrome / Edge / Firefox. Click PLAY.
  (Needs an internet connection once to load Three.js r128 from the cdnjs CDN.)

CONTROLS
  WASD move | Space jump | Shift sprint | Mouse aim | LMB fire / stab
  1 / 2 / 3 or wheel: Rifle / Pistol / Knife | R reload
  Z wall | X floor (look down or jump while pressing = tower up) | C stairs | V break your own build
  Esc pause

RULES
  You vs 5 bots. 100 health + 100 shield (shield absorbs damage first).
  First to 15 eliminations wins. Dead players respawn after 3 seconds.
  All builds can be destroyed by gunfire.

SETTINGS (main menu / pause)
  Mouse sensitivity, master volume, FOV, AI difficulty (Easy / Medium / Hard), invert Y.
